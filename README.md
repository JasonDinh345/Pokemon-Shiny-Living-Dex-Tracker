<h1>PrismaDex</h1>
<p>Pokemon Shiny Living Dex Tracker created with Next.js with a Node.js RESTful API using Prisma</p>
The purpose of this project was to reinforce my knowledge with Next.js and to learn how to deploy my API using AWS

**<p>AWS Instance will most likely be closed to save costs</p>**

<h1>Learned</h1>
<ul>
  <li>AWS</li>
    <ul>
      <li>Deploying EC2 instance for backend</li>
      <li>Using Linux to access instance with ssh</li>
      <li>Uses Caddy and AWS's Route 53 with a custom domain to host on HTTPS</li>
    </ul>
  <li>Prisma</li>
    <ul>
      <li>Creating a schema file for Prisma</li>
      <li>Utilizing Prisma to communicate to my database in my service layer</li>
    </ul>
</ul>
